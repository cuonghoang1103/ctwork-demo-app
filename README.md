# CT Work Demo App

A tiny online-shop front end used as the **sample repository** for the `DEMO` project in
[CT Work](https://cuongthai.com/work) — the team work-management app by CuongThai.

It exists so the CT Work **Code** page has real Git activity to show: commits, branches and a
pull request whose messages mention issue keys such as `DEMO-4`. CT Work links every commit,
branch and pull request that mentions an issue key to that issue.

## Run it

Open `index.html` in a browser. No build step, no dependencies.

## Structure

| Path | What it is |
|---|---|
| `index.html` | Product list page |
| `src/cart.js` | Shopping cart logic (add, remove, totals) |
| `src/auth.js` | Sign-up / sign-in form validation |
| `src/styles.css` | Styles |
